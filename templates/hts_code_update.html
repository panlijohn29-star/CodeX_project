Step 1 - Load Excel into the temp table

Choose exp-code.txt first, then imp-code.txt. If both are chosen they are used instead of the Excel file.
Ready
  • Database: scdbus, table s_sys_dict_outside_code_hts202501.
  • Option B: EXP rows are kept, IMP rows whose code is not in EXP are added, sorted by code (this replaces the old build_hts script). Fixed-width columns: code, long description, unit 1, unit 2.
  • Option A: first sheet, header row with FREE_FIELD1 (HTS code, 10 digits), FREE_FIELD2 (description), FREE_FIELD3, FREE_FIELD4 (or hs, lalpha, auq1, AUQ2). Other columns (such as IMP_EXP) are ignored.
  • Rows are loaded with SYS_CODE_ID = 0 and SYS_CODE_TYPE_ID = 2016110115490001.
  • The whole table is emptied first, then the file is loaded. Codes that are in the table but not in the file are removed.
  • Every loaded row gets REMARK = today's date (YYYY-MM-DD).
  • The file must have no invalid rows (bad or duplicate codes). Fix them and upload again.
  • The table is truncated and cannot be rolled back. If the load fails, fix the problem and upload again.
  • Nothing is changed until you confirm.
